#Taskora

Taskora is a lightweight task management web application built as my first full-stack project. It helps users organize, manage, and track tasks efficiently while focusing on a clean UI and practical real-world features.

The project is developed using Next.js, Node.js, and MongoDB, with secure authentication, real-time updates, and modern UI components. Some features are still under development, and the project will continue to evolve as I enhance functionality and performance.

Taskora reflects my learning journey in full-stack development, covering frontend design, backend architecture, authentication, and deployment.
